Código aberto · TCC

Nasce do mesmo repositório.

O app não é um projeto novo — é o front do PlayDB rodando dentro de um casco nativo. O que já está no ar vira o que está no bolso.

Coleta em Python (FastAPI + Postgres), painel em React, tudo em camadas MVC. O empacotamento pro Android reaproveita a mesma build do dashboard — só troca o casco do navegador por um WebView nativo.
